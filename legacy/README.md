# Legacy notebooks

This folder preserves the original MSNBC notebooks, including their saved outputs:

1. [Data Processing](MSNBC%20Web%20-%20Data%20Processing.ipynb): organize browsing sequences and derive visit and transition metrics.
2. [Data Analysis](MSNBC%20Web%20-%20Data%20Analysis.ipynb): explore the derived metrics and visualize weighted graphs.

Historical source: [Data_Projects / MSNBC Network Analysis](https://github.com/jcmacmwu23/Data_Projects/tree/84820b7f3f779ba78965c2a47148961e2650e991/MSNBC%20Network%20Analysis).

These notebooks are historical artifacts, not the supported execution path. They may contain older library APIs, original local paths, and dependencies on large intermediate files that are not included here. Their saved analyses are preserved without rewriting historical claims.

Use [the modern implementation](../modern/msnbc/README.md) for the tested setup and reproducible CSV pipeline. The original reasoning is retained while transformations are re-expressed as modular, validated Python code.
